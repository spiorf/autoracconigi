# autoracconigi

Repository del sito di **Autoracconigi** (Torino).

Il sito viene generato dal computer del negozio (pannello locale → «Genera e pubblica su GitHub»)
e pubblicato nel branch `gh-pages`, che GitHub Pages serve all’indirizzo
`https://spiorf.github.io/autoracconigi/`.

- Non modificare a mano i file del branch `gh-pages`: ogni pubblicazione li sostituisce,
  comprese le pagine che non vengono più generate.
- Testi, recapiti, orari e vetture si cambiano dal pannello, non qui.
